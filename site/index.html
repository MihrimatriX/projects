Çalıştırma

Repoyu klonlayın; başlatıcı eksik araçları winget ile kurmayı önerir.

# grafik başlatıcı
.\DevProjects.exe
# konsol menüsü
.\launcher.cmd
# isim parçasıyla doğrudan başlat
.\launcher.ps1 -Run regex
# gerekli SDK'lar kurulu mu?
.\launcher.ps1 -Doctor
# bağımsız exe üret (dist\<proje>\)
.\launcher.ps1 -Publish all

Gereksinimler: .NET 10 SDK, Flutter 3.x, Python 3.11+, Node.js 22.12+. İsteğe bağlı: Rust, ffmpeg.

Her projenin run.ps1 dosyası tek başına da çalışır; testler için .\run.ps1 -Check.

Flutter projelerinin Windows exe'si için Windows Geliştirici Modu açık olmalıdır.

run.ps1 açılmıyorsa: Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
